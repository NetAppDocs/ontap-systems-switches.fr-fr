= Flux de travail d'installation et de configuration des commutateurs de cluster Cisco Nexus 3132Q-V
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Suivez cette procédure pour installer et configurer les commutateurs de cluster Cisco Nexus 3132Q-V dans un environnement ONTAP. Le 3132Q-V prend en charge les clusters ONTAP comportant plus de deux nœuds.

Suivez ces étapes de flux de travail pour installer et configurer votre commutateur Cisco Nexus 3132Q-V.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Un"]link:configure-reqs-3132q.html["Exigences de configuration"]
[role="quick-margin-para"]
Examinez les exigences de configuration du commutateur de cluster 3132Q-V.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Deux"]link:required-documentation-3132q.html["Documents requis"]
[role="quick-margin-para"]
Consultez la documentation spécifique du commutateur et du contrôleur pour configurer vos commutateurs 3132Q-V et le cluster ONTAP.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Trois"]link:smart-call-home-3132q.html["Exigences de Smart Call Home"]
[role="quick-margin-para"]
Passez en revue les exigences de la fonctionnalité Cisco Smart Call Home, utilisée pour surveiller les composants matériels et logiciels de votre réseau.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quatre"]link:install-hardware-workflow.html["Installez le matériel"]
[role="quick-margin-para"]
Installez le matériel du commutateur.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Cinq"]link:configure-software-overview-3132q-v-cluster.html["Configurer le logiciel"]
[role="quick-margin-para"]
Configurer le logiciel du commutateur.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["Six"]link:../switch-cshm/config-overview.html["Configurer CSHM"]
[role="quick-margin-para"]
Configurer le contrôle de l'état du commutateur.
