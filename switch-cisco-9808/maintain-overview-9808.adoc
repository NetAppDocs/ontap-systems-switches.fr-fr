= Maintenir une vue d'ensemble - Cisco Nexus 9808
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Assurez la maintenance de votre commutateur Cisco Nexus 9808 pour une fiabilité à long terme et des performances optimales. Vous pouvez effectuer des opérations de maintenance telles que le remplacement de composants défectueux (FRU), le remplacement d'un commutateur défectueux et la réinitialisation d'un commutateur à ses paramètres d'usine par défaut.

Vous pouvez effectuer les tâches de maintenance suivantes sur un commutateur :

* link:maintain-replace-frus-9808.html["Remplacez les FRU"]
* link:maintain-reset-switch-9808.html["Réinitialiser un commutateur aux paramètres d'usine par défaut"]
