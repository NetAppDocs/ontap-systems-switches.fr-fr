= Découvrez les options de maintenance pour le commutateur Cisco Nexus 9808
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Examinez les tâches de maintenance disponibles pour les commutateurs Cisco Nexus 9808, notamment le remplacement des composants défectueux du commutateur (FRU), le remplacement d'un commutateur défectueux et la réinitialisation d'un commutateur aux paramètres d'usine par défaut.

Vous pouvez effectuer les tâches de maintenance suivantes sur un commutateur :

* link:maintain-replace-frus-9808.html["Remplacez les FRU"]
* link:maintain-reset-switch-9808.html["Réinitialiser un commutateur aux paramètres d'usine par défaut"]
