= Découvrez les options de maintenance pour le commutateur Cisco Nexus 9364D-GX2A

:icons: font
:imagesdir: ../media/


[role="lead"]

Vous pouvez effectuer les tâches de maintenance suivantes sur un commutateur :

* link:maintain-replace-frus-9364d.html["Remplacez les FRU"]
* link:maintain-reset-switch-9364d.html["Réinitialiser un commutateur aux paramètres d'usine par défaut"]
