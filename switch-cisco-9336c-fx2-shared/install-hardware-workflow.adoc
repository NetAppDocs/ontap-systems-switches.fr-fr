= Flux de travail d'installation matérielle pour les commutateurs partagés Cisco Nexus 9336C-FX2
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Suivez ce flux de travail pour installer et configurer le matériel pour un commutateur partagé Cisco Nexus 9336C-FX2.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Un"]link:cable-9336c-shared.html["Complétez la fiche de câblage"]
[role="quick-margin-para"]
La fiche de câblage type fournit des exemples d'affectations de ports recommandées entre les commutateurs et les contrôleurs.  La feuille de calcul vierge fournit un modèle que vous pouvez utiliser pour configurer votre cluster.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Deux"]link:install-9336c-shared.html["Installez l'interrupteur"]
[role="quick-margin-para"]
Installez le commutateur 9336C-FX2.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Trois"]link:install-switch-and-passthrough-panel-9336c-shared.html["Installez le commutateur dans une armoire NetApp."]
[role="quick-margin-para"]
Installez le commutateur 9336C-FX2 et le panneau de passage dans une armoire NetApp selon les besoins.
