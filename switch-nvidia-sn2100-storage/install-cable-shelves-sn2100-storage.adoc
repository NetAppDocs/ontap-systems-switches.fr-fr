= Câblez les baies de disques NS224 comme stockage connecté à un commutateur pour les commutateurs de stockage NVIDIA SN2100
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Câblez les baies de disques NS224 comme stockage connecté à un commutateur en utilisant les commutateurs de stockage NVIDIA SN2100 lorsque le stockage à connexion directe ne convient pas à votre configuration.

* Câbler les étagères de lecteurs NS224 à travers les commutateurs de stockage :
+
https://library.netapp.com/ecm/ecm_download_file/ECMLP2876580["Informations relatives au câblage des baies de disques durs NS224 à commutateur"^]

* Installez vos commutateurs de stockage :
+
https://docs.netapp.com/us-en/ontap-systems-switches/index.html["Documentation relative aux commutateurs AFF et FAS"^]

* Confirmez le matériel pris en charge, comme les commutateurs de stockage et les câbles, pour votre modèle de plateforme. Consultez la link:https://hwu.netapp.com/["Hardware Universe"^] pour plus de détails.
