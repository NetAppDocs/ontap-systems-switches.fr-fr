= Flux de travail d'installation matérielle pour les commutateurs de cluster Cisco Nexus 9336C-FX2 et 9336C-FX2-T
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Suivez ce flux de travail pour installer et configurer le matériel pour les commutateurs de cluster Cisco Nexus 9336C-FX2 et 9336C-FX2-T.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Un"]link:setup-worksheet-9336c-cluster.html["Complétez la fiche de câblage"]
[role="quick-margin-para"]
La fiche de câblage type fournit des exemples d'affectations de ports recommandées entre les commutateurs et les contrôleurs.  La feuille de calcul vierge fournit un modèle que vous pouvez utiliser pour configurer votre cluster.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Deux"]link:install-switch-9336c-cluster.html["Installez l'interrupteur"]
[role="quick-margin-para"]
Installez les commutateurs 9336C-FX2 et 9336C-FX2-T.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Trois"]link:install-switch-and-passthrough-panel-9336c-cluster.html["Installez le commutateur dans une armoire NetApp."]
[role="quick-margin-para"]
Installez les commutateurs 9336C-FX2 et 9336C-FX2-T et le panneau de passage dans une armoire NetApp selon les besoins.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quatre"]link:install-switch-and-passthrough-panel-9336c-cluster.html["Vérifier le câblage et la configuration"]
[role="quick-margin-para"]
Consultez la prise en charge des ports Ethernet NVIDIA , les exigences FEC 25 GbE et les informations sur les ressources TCAM.
