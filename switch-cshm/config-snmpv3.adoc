= Configurer SNMPv3 pour le contrôle de l'état du commutateur Ethernet
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Configurez SNMPv3 sur vos commutateurs réseau pour activer une communication sécurisée et authentifiée avec le contrôle de l'état du commutateur Ethernet (CSHM). SNMPv3 permet l'interrogation chiffrée de l'état des commutateurs pour la surveillance de l'état dans ONTAP.

Le CSHM (Ethernet Switch Health Monitor) utilise SNMP pour surveiller l'état et les performances des commutateurs réseau. Par défaut, SNMPv2c est configuré automatiquement via le Reference Configuration File (RCF). SNMPv3 est plus sécurisé que SNMPv2 car il introduit des fonctionnalités de sécurité robustes telles que l'authentification, le chiffrement et l'intégrité des messages, qui protègent contre les accès non autorisés et garantissent la confidentialité et l'intégrité des données lors de leur transmission.

[NOTE]
====
* SNMPv3 n'est pris en charge que sur ONTAP 9.12.1 et versions ultérieures.
* Les versions ONTAP 9.13.1P12, 9.14.1P9, 9.15.1P5, 9.16.1 et ultérieures corrigent ces deux problèmes :
+
** link:https://kb.netapp.com/on-prem/ontap/OHW/OHW-Issues/CONTAP-82891["Pour la surveillance de l'état des commutateurs Cisco ONTAP , le trafic SNMPv2 peut encore être observé après le passage à SNMPv3."^]
** link:https://kb.netapp.com/on-prem/ontap/OHW/OHW-Issues/CONTAP-119131["Alertes erronées concernant le ventilateur et l'alimentation en cas de défaillance SNMP."^]




====
.À propos de cette tâche
Les commandes suivantes permettent de configurer un nom d'utilisateur SNMPv3 sur les commutateurs *Broadcom*, * Cisco* et * NVIDIA* :

[role="tabbed-block"]
====
.Commutateurs Broadcom
--
Configurez un nom d'utilisateur SNMPv3 NETWORK-OPERATOR sur les commutateurs Broadcom BES-53248.


NOTE: À partir d'ONTAP 9.20.1, vous pouvez configurer l'authentification SHA-512 sur les commutateurs Broadcom.

* Pour les *sans authentification* :
+
[source, cli]
----
snmp-server user <snmpv3-user> NETWORK-OPERATOR noauth
----
* Pour l'authentification *MD5/SHA/SHA-512*:
+
[source, cli]
----
snmp-server user <snmpv3-user> NETWORK-OPERATOR [auth-md5|auth-sha|auth-sha512]
----
* Pour l’*authentification MD5/SHA/SHA-512 avec chiffrement AES/DES*:
+
[source, cli]
----
snmp-server user <snmpv3-user> NETWORK-OPERATOR [auth-md5|auth-sha|auth-sha512] [priv-aes128|priv-des]
----


La commande suivante configure un nom d'utilisateur SNMPv3 côté ONTAP :

[source, cli]
----
security login create -user-or-group-name <snmpv3-user> -application snmp -authentication-method usm -remote-switch-ipaddress <address>
----
La commande suivante établit le nom d'utilisateur SNMPv3 avec CSHM :

[source, cli]
----
cluster1::*> system switch ethernet modify -device <switch-name> -snmp-version SNMPv3 -community-or-username <snmpv3-user>
----
.Étapes de l'exemple
. Configurez l'utilisateur SNMPv3 sur le commutateur pour utiliser l'authentification SHA et le chiffrement AES-128 :
+
[listing, subs="+quotes"]
----
(sw1)(Config)# *snmp-server user SNMPv3shaAes128 NETWORK-OPERATOR auth-sha priv-aes128*

(sw1)(Config)# *show snmp user snmp SNMPv3shaAes128*

+

.Commutateurs Cisco
--
Configurez un nom d'utilisateur SNMPv3 `<snmpv3-user>` sur les commutateurs Cisco Nexus.


NOTE: À partir d'ONTAP 9.20.1, vous pouvez configurer l'authentification SHA-512 ou SHA-256 sur les commutateurs Cisco.

* Pour les *sans authentification* :
+
[source, cli]
----
snmp-server user <snmpv3-user> NoAuth
----
* Pour l'authentification *MD5/SHA/SHA-256/SHA-512*:
+
[source, cli]
----
snmp-server user <snmpv3-user> auth [md5|sha|sha-256|sha-512] <auth-password>
----
* Pour l'authentification *MD5/SHA/SHA-256/SHA-512 avec chiffrement AES/DES* :
+
[source, cli]
----
snmp-server user <snmpv3-user> AuthEncrypt auth [md5|sha|sha-256|sha-512] <auth-password> priv [aes-128|des] <priv-password>
----
