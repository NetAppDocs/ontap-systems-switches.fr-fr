= Flux de travail d'installation et de configuration du commutateur de cluster Broadcom BES-53248
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Suivez cette procédure pour installer et configurer un nouveau commutateur de cluster Broadcom BES-53248 dans un environnement ONTAP. Le BES-53248 est un commutateur physique prenant en charge les clusters ONTAP de deux à 24 nœuds.

Suivez ces étapes de flux de travail pour installer et configurer vos commutateurs BES-53248.

[role="quick-margin-para"]
