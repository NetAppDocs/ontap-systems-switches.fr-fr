= Flux de travail d'installation matérielle pour les commutateurs de cluster Cisco Nexus 92300YC
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Suivez ce flux de travail pour installer et configurer le matériel des commutateurs de cluster Cisco Nexus 92300YC.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Un"]link:setup-worksheet-92300yc.html["Complétez la fiche de câblage"]
[role="quick-margin-para"]
La fiche de câblage type fournit des exemples d'affectations de ports recommandées entre les commutateurs et les contrôleurs.  La feuille de calcul vierge fournit un modèle que vous pouvez utiliser pour configurer votre cluster.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Deux"]link:install-switch-92300yc.html["Installez l'interrupteur"]
[role="quick-margin-para"]
Installez le commutateur 92300YC.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Trois"]link:install-switch-netapp-cabinet-92300yc.html["Installez le commutateur dans une armoire NetApp."]
[role="quick-margin-para"]
Installez le commutateur 92300YC et le panneau de passage dans une armoire NetApp selon les besoins.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quatre"]link:cabling-considerations-92300.html["Vérifier le câblage et la configuration"]
[role="quick-margin-para"]
Vérifiez la prise en charge des ports Ethernet NVIDIA.
